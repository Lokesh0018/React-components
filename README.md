# React Components Collection

A curated collection of modern, animated, and responsive React components built with Vite and Tailwind CSS (or standard CSS).

> **Attribution:** This project was initially inspired by and based upon the excellent component library by [frontend-joe](https://github.com/frontend-joe). It has since been adopted, reorganized, and further developed to serve as a personal component library.

## 🚀 Features

- **Component Driven:** Modular and isolated components.
- **Animations:** Extensive use of Framer Motion and GSAP for smooth transitions.
- **Ready to Use:** Drop-in components for Navbars, Sidebars, Modals, Buttons, and more.

## 📦 Components Included

- **Navigation:** Navbars, Sidebars, Dropdowns
- **Interactive:** Modals, Accordions, Carousels, Parallax
- **Inputs & Forms:** Buttons, Controls, Logins, Signups
- **Data Display:** Tables, Cards, Widgets
- **Animations:** GSAP specific animations

## 🛠 Getting Started

### Prerequisites

- Node.js (v18+)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Lokesh0018/React-components.git
   cd React-components
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```
